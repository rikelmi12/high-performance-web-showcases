# High-Performance Web & E-Commerce Showcases

A curated collection of modern, production-grade digital showcases, Awwwards-concept landing pages, and interactive e-commerce catalogs engineered for **sub-second performance**, native browser fluidity, and high conversion.

---

## 🚀 Projects Included

### 1. Mundo Náutica (`/Mundonauticasma`)
- **Live Demo:** [softcore.cloud/Mundonauticasma](https://softcore.cloud/Mundonauticasma/)
- **Core Engineering:**
  - **100% Native Browser Scrolling:** Zero JS interception of scroll/wheel events, ensuring 60fps / 120fps smooth scrolling across mobile and desktop.
  - **CSS Scroll-Driven Animations:** Hardware-accelerated progress tracking and reveal animations.
  - **IntersectionObserver Architecture:** Lazy execution for off-screen components and decorative animations.
  - **Schema.org JSON-LD:** Full rich snippet SEO structured data for retail indexing.
  - **Asset Optimization:** WebP image pipeline, responsive resolution sets, and zero bloated frameworks.

### 2. Pharmativa (`/pharmativa`)
- **Live Demo:** [softcore.cloud/pharmativa](https://softcore.cloud/pharmativa/)
- **Core Engineering:**
  - Modern healthcare and dermocosmetics responsive catalog.
  - Mobile-first architecture with instant touch response.
  - Automated lead generation and order dispatch routing via WhatsApp.

### 3. SoftTec (`/softtec`)
- **Live Demo:** [softcore.cloud/softtec](https://softcore.cloud/softtec/)
- **Core Engineering:**
  - Interactive personal technology and engineering portfolio for **Ruan Rikelmi (Rikelmif)**.
  - 3D interactive graphics (GLB models, custom shaders, Earth rendering).
  - Modern typography and clean architectural case studies.

## 🛠️ Tech Stack

- **HTML5 & Modern CSS:** CSS Grid, Flexbox, Scroll-Driven Animations, View Transitions
- **JavaScript:** Vanilla ES6+, IntersectionObserver API, GSAP Animations
- **Assets:** WebP / SVG lightweight graphics, 3D GLB models
- **SEO & Structured Data:** Schema.org JSON-LD
